# Example use case

This folder shows the exact shape a community submission takes. It is **not** a
real use case and is excluded from the aggregate `catalog.yaml`, but CI validates
it with the same rules, so it always stays correct.

```
example/
└── blueprints/
    └── example-chatbot-1.0.0.yaml   # one kind: Blueprint per file
```

To contribute, copy this layout to `community/<your-usecase>/` and open a pull
request. See [CONTRIBUTING.md](../CONTRIBUTING.md).
